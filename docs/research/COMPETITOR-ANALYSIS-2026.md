# Competitor analysis: AI website builders (2026)

Read date for every source below: **2026-11-07**. Method: official product pages, help centres and docs only (competitor blogs are used only where noted). Firecrawl was not used.

**Legend.** **V** = verified: stated in a docs/help/pricing page, concrete and checkable. **M** = marketing claim: superlative or unquantified promise. "NF" = _not found in official sources_ (nothing filled from memory).

**Evidence-quality caveats (read first)**

- Webflow: `help.webflow.com` returned HTTP 403 and `webflow.com/ai-site-builder` / `/updates/*` failed with a parse error. Webflow facts below come from **search-result summaries of the official help/pricing pages**, not from a full page read. Treat as V-with-lower-confidence ("V-snippet").
- Squarespace plan credit numbers and Wix paid-plan prices come from search summaries of the pricing pages (the credits help articles themselves were fetched; see per row).
- Several vendors' pages disagree with each other (Framer credits, Hostinger templates count, Durable price, Relume Pro price). Conflicts are recorded, not resolved.
- Framer's `/wireframer/` page appeared to contain placeholder/demo content (placeholder testimonials, unfamiliar model names); only its structural claims are used and flagged.

## 3. Reusable design and product principles

Principles only; nothing here copies any vendor's design, copy or code. Status: **V** = the underlying behaviour is verified in official docs; **M** = only marketing asserts the benefit.

| #   | Principle for Kora                                                                                                                                                                                      | Observed in                                                                                                                                                                                   | Status                                                                               |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| P1  | **Minimal-input start with an editable summary.** Collect a few answers into a visible, editable profile before generating, letting the owner accept a suggestion, skip, or type.                       | Wix (Site Profile, suggest/skip), Durable (3 questions), Hostinger (700-char prompt)                                                                                                          | V                                                                                    |
| P2  | **Accept evidence instead of more typing.** Let owners drop a URL, document, screenshot or brand file as the source of facts and style.                                                                 | Hostinger (10 files, link, screenshot), Relume Publish (PDF, brand guidelines, URL), Framer (URLs/files/`@`-refs), Lovable (URL import)                                                       | V                                                                                    |
| P3  | **Show the structure before the pixels.** Propose a page list/sitemap the owner can add to or remove from before full generation.                                                                       | Webflow (structure then per-page layout), Relume (sitemap, wireframe), Wix older flow (tick pages)                                                                                            | V                                                                                    |

## 4. Where Kora is different / at risk

Grounded only in what was verified above plus Kora's own README (single business profile, versioned Brand Kit, post-launch monitoring and typed fixes, approvals).

**Where Kora appears different (verified gap in competitors' documentation)**

1. **Post-launch reliability is not documented by any of the nine.** None of the official pages read describes uptime monitoring of the customer's live site, evidence-based diagnosis, approval-gated fixes, or verified recovery. Lovable documents only that the site stays up when credits run out and that abuse protection runs; Durable documents SEO/GEO tracking; Framer documents analytics/redirects. (Absence from the pages I read, not proof competitors lack it.)
2. **One factual business profile feeding site, channels and content.** Durable (business profile -> structured data, CRM, bookings) and Wix (Site Profile) come closest. Neither page documents cross-channel consistency checks.
3. **Honest limit statements.** Competitors mostly document "may be inaccurate" generically; none documents per-claim fact-binding of generated text to owner-supplied facts.

**Where Kora is at risk**

1. **Commodity "generate a site from a few answers" is saturated.** Wix, Durable, Hostinger, Squarespace all verifiably start from chat/3 questions/<=700 chars, and Durable states unlimited AI-generated pages on every plan with a free private preview. Input-minimality alone is not a differentiator.
2. **Bundled business tools at low price.** Durable Launch ($22-25/mo) includes hosting, forms, CRM, unlimited bookings and 1,000 credits; Hostinger bundles hosting, mailbox, domain and booking from $1.99-$7.99/mo (48-month promo). Kora's monitoring/recovery value must be priced against these bundles.
3. **Editor expectations are high.** Framer (branches, layer edits, undo) and Wix/Squarespace (visual editor + chat) set a bar for localized, reversible edits; Lovable adds visual edits and code access.
4. **Hosting trust and portability.** Lovable and Relume Export advertise code/design export; Wix and Lovable document lock-in constraints. Owners comparing Kora will ask about exit paths.
5. **Credit cost transparency.** Lovable publishes per-action credit examples; Framer publishes 80%/100% behaviour; Wix says Aria chat is free. An opaque or surprise-metered Kora generation path would look worse by comparison.
6. **Image provenance is undocumented almost everywhere.** Only Squarespace (Blueprint images are AI-generated) states a source. If Kora uses stock or AI images, stating provenance clearly is a cheap trust win; but we found no competitor evidence of how owners react.
7. **Weakly verified items.** Webflow's details are from search summaries only; Framer's wireframer page contained placeholder content; competitors' prices conflict across their own pages. Re-verify before using any figure in external material.
