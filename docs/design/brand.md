# Kora brand: calm control

**Idea.** Kora watches so you do not have to. The product should feel like a quiet, competent colleague: nothing shouts, everything is where you expect, and when something does need you,
it says so plainly and asks before it changes anything that matters.

**Motif: the level line.** A single steady line with a marker. It stays level when all is well, dips when something breaks, returns when recovery is verified. It appears in the hero scene, the
"Calm control" band and the recovery story, and it is the same idea as the product's promise: a fix only counts once new observations show the line is level again.

**Visuals.** A real product scene (a generated site, a _Healthy_ card, a _Waiting for approval_ card) rather than abstract stock art. Six generated showcase sites from six industries, clearly labelled as
examples from short briefs with fictional businesses. Editorial rhythm: big serif headline, generous space, one dark "Calm control" band, numbered steps, then the recovery story.
Type: DM Serif Display for headlines, Manrope for text (both bundled, the same files customer sites use). Colour: paper `#f6f5f0`, ink, one deep green `#0b6e5f`; amber and red only for states.

## Voice

- Say what happened, what Kora knows, and what it does not know. Never claim a cause the evidence does not show.
- Plain words. "Your website is reachable, but the application is returning an error", not "5xx detected".
- Calm verbs, no exclamation marks, no hype ("seamless", "unlock", "supercharge"), no fear.
- Ask before acting on anything customers can see. Say it asks.
- Numbers only when real. Illustrations are labelled _Illustration, not live data_.
- Never promise uptime; promise honesty and proof.

## Status language (everywhere: dashboard, incident page, notifications, tests)

**Healthy · Watching · Needs attention · Waiting for approval · Fixing · Checking recovery · Recovered** (plus _Not published yet_ for a site that has no live address).
Always label + icon + colour, never colour alone. Owner mode shows these and one plain sentence. Proof mode shows evidence, diagnosis, policy decision, approval, verification and the Passport.
