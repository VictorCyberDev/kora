# Bundled fonts

All families are licensed under the SIL Open Font License 1.1 (commercial use allowed, bundling allowed, no sale of the fonts on their own). Files are the Latin subsets distributed by Fontsource (`@fontsource/*` 5.3.0).

Inter, Manrope, Playfair Display, DM Serif Display, Lora, DM Sans, Space Grotesk, Outfit, Nunito, JetBrains Mono, Cormorant Garamond, Syne, Plus Jakarta Sans, Bricolage Grotesque.

Each generated website loads only the one to three files its design system selects.

Added for the v7 creative system (all SIL OFL 1.1, Fontsource 5.3.0 Latin subsets): Fraunces, Instrument Serif, Bodoni Moda, Barlow Condensed, Oswald, Bebas Neue, Archivo, Sora, Fredoka, Young Serif, Newsreader, Marcellus, Work Sans, Unbounded, Gloock, Caveat, Libre Baskerville, Epilogue. Italic faces exist only where listed in `fonts.json` (suffix `i`).
